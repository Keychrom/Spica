# client — Spica のフロントエンド（案K「雅＋」）

案K（雅＋ / MIYABI PLUS）で**一から書き直したフロントエンド**です。
2026-10-10 に旧フロントエンドと入れ替えて、これが Spica の標準になりました
（サーバーは `client/dist` を配信します）。

```
┌─ デザインの出どころ ────────────────────────────────┐
│ design/k-miyabi-plus.html   … モックアップ（見た目の正） │
│ design/README.md            … 提案の全体（決定事項）     │
└──────────────────────────────────────────────────┘
```

## 動かす

サーバーと一緒に起動するとき（推奨）:

```bash
npm run dev               # サーバー（3000）＋ 画面（5174）
```

画面だけを起動したいとき:

```bash
npm run dev:client        # → http://localhost:5174
```

API は既定で、いま動いている本番相当のインスタンス（`http://localhost:3210`）へ転送します。
向き先を変えたいとき:

```bash
SPICA_API=http://localhost:3000 npm run dev:client
```

- ビルド: `npm run build`（ルートから。サーバーとクライアントの両方）／ `client/dist` に出ます
- 大きさの検査: `npm run check:size`（300 行を超えたファイルを教える）

## いまできること

- **ホームタイムライン**（ホーム / ローカル / 連合、カーソルで続きの読み込み）
- **プロフィール**（`/users/:id`。バナー・アイコン・自己紹介・項目・ノート / メディア / フォロー / フォロワー・ピン留め・フォロー / ミュート / ブロック）
- **ノートの 1 枚**（`/users/:user/posts/:id`。返信先と返信の連なり。通知や検索から飛ぶ先）
- **設定**（`/settings`。プロフィール / 表示 / 通知 / アカウント / つながり / データ の 6 節）
  - 表示: 文字の大きさ・行のつめ方・既定のタブ・返信やリノートの表示（アカウントに保存して次の訪問でも効く）
  - アカウント: ログイン中の端末の一覧と解除・パスワードの設定 / 変更・メールアドレスの設定と確認
  - つながり: 承認待ちのフォロー・ミュート / ブロックの一覧と解除
  - データ: 自分のノートの持ち出し（ZIP / JSON。できあがりを待ってダウンロード）
- **メッセージ**（`/messages`。会話の一覧・やりとり・送信。サーバーで DM が有効なときだけ）
- **新規登録**（`/register`。招待コード・承認制・規約同意・メール確認にも対応。登録直後にマスターキーを表示し、**ワンクリックでコピー**できます）
- **はじめての設定**（`/onboarding`。ようこそ → 見た目と通知 → プロフィール → マスターキー → 公開の設定 → フォロー → 完了 の 7 ステップ。
  登録直後に通るほか、まだの人のタイムライン上部に案内が出ます）
- **画面名はタブに追従**（ローカルを選べば見出しも「ローカル」に）。**タグページ**（`/tags/:tag` → 見出しは `#タグ`）
- **通知**（すべて / メンション / リアクション / フォロー。同じ種類はまとめて顔を並べる。1 件ずつ既読 / すべて既読。未読は左ナビに件数）
- **見つける（検索）**（`/search?q=`。ユーザーとノートに分けて表示。`from:` `has:media` などの演算子もそのまま渡す。空のときは話題のタグ）
- **ブックマーク / リスト / アンテナ / チャンネル**（1 つの画面で兼ねる。選んだものを URL に持たせる ＝ `/lists/:id`）
- **ドライブ**（一覧・サムネイル・容量・投稿で使用中の表示と削除）
- **落ちても白画面にしない**（ErrorBoundary。ナビは残したまま、その画面だけ差し替える）
- **投稿の表示**（本文・CW（開く）・メディア・引用・アンケート・リアクション・リノート表示）
- **操作**（リアクション / ブックマーク / リノート / 共有 = URL コピー）
- **投稿の ⋯**（自分の投稿: 本文と注記の編集・プロフィールにピン留め・削除 / 他人の投稿: 通報。運営は他人の投稿も削除）
- **アンケートの投票**（1 つだけ / 複数。投票すると結果が出る）
- **下書きと予約投稿**（`/drafts`。ノートを作成の「下書きに保存」「予約する」、続きから書く・取り消す）
- **ミュートワード**（設定 → つながり。言葉を登録するとタイムラインで畳まれる）
- **パスキー（指紋・顔・PIN でログイン）**（設定 → 安全。**実機の認証器が要るため未検証**。登録・一覧・削除は実装済み）
- **端末への通知（Web Push）**（設定 → 通知。購読・解除・テスト送信。サーバーに VAPID の設定があるときだけ動きます）
- **持ち出したものの取り込み**（設定 → データ。書き出した ZIP / JSON を選んで読み込む）
- **安全**（設定 → 安全。**2段階認証**（認証アプリ・リカバリーコード）・**引っ越し**（引っ越し先の登録と実行）・**アカウントの削除**・**自分が送った通報の履歴**）
  - 削除の本人確認は**サーバーの認証方式に合わせます**。従来型（メール＋パスワード）のサーバーでは**パスワード**（マスターキーは使いません）、マスターキー方式のサーバーではマスターキー（ほかに方法が無いため）。同じ考え方で、**パスワードを設定済みの人にはマスターキーを求めません**
- **本文に入れる絵文字ピッカー**（ノートを作成の「絵文字」。カスタム絵文字をカーソル位置に差し込む）
- **リスト・アンテナ・チャンネルの作成と編集**（`/lists` などの「＋ 作る」「編集」。アンテナは拾う条件と通知、チャンネルは説明・色・フォロー）
- **ノートの作成**（本文・CW・公開範囲・返信・引用・**センシティブ**・**画像/動画/音声の添付（ALT つき・6 枚まで）**・**アンケートの作成（複数選択・締切）**）
- **ノートの見え方**（時刻は設定に合わせて日時 / 〜前。**動画はその場で再生**（自動再生とミュートは設定しだい）・**センシティブな添付は覆いの下**（「常に隠す」が入のとき）・リアクションは**最近使ったもの → 既定 → 定型**の順）
- **ログイン**（マスターキー / メール＋パスワード / 2段階認証のコード入力）
- **テーマとアクセントカラー**（ライト / ダーク / 端末に合わせる。アクセントは紫・水色・緑・赤紫・赤・橙の 6 色。
  設定 → 表示 で変えると**サーバーにも残る**ので、別の端末・別のブラウザでも同じ見た目になります）
- **欄外**（サーバー情報・話題のタグ・おすすめ＋フォロー）
- **リアルタイム更新（SSE）**（ログイン中はつなぎっぱなし。新着ノート・リアクション・リノート・アンケートの結果・削除・通知がその場で届く。
  右カラムに「リアルタイム 接続中」を表示。切れたらチケットを取り直して張り直す）
- **管理パネル**（`/admin`。運営だけ）
  - **概要**（数字・連合・最近の操作）・**利用者**（絞り込み・凍結/解除・管理者の付け外し・削除）・**通報**（対応した / 対応しない / 未対応に戻す）
  - **登録の承認**（承認制の申請を承認 / 拒否）・**サーバー設定**（名前・説明・アイコン/バナー・登録の受け入れ方・ルール・リンク）・**絵文字・招待**（カスタム絵文字と招待コードの追加 / 削除）
  - **リレー**（追加 / 受け入れ・停止 / フォローの再送 / 削除）・**ブロック**（サーバー単位で追加 / 解除）・**メンテナンス**（いまの大きさ・手動実行・キャッシュ削除・毎日実行と画像プロキシの切り替え・**リモートの扱い**（検索の索引に入れる範囲 / ブーストの保存方針））
  - **ロール**（作成 / 編集 / 削除。できることは「モデレーター」「お知らせの投稿」「管理者」の組み合わせ）・利用者ごとの配布（**利用者**の「ロール」から）
  - **お知らせ**（作成 / 出し入れ / 編集 / 削除。出しているあいだ、利用者の画面のいちばん上に帯で出る）
  - **メール・ストレージ**（SMTP の設定と接続テスト。S3 互換のメディア保存先の設定と接続テスト）
  - **配信キュー**（届くのを待っている / 送信中 / 届いた / あきらめた・待ち行列と最近の失敗・再送の前倒しと失敗分の削除）
  - 概要の**監査ログの整理**（180 日より前の記録を消す）・サーバー設定の**メッセージ（DM）の入切**
- **お知らせの帯**（`/api/announcements`。出ているあいだ、どの画面でも本文の上に出る。閉じるとその回のあいだは出さない）
- **つながりの設定**（設定 → つながり。**メッセージ（DM）の受け取り**（誰からも受け取らない / 許可した相手だけ。相手は @user@host かプロフィールのURLで足す）・**ドメインミュート**・ミュートワード・ブロック・ミュート）
- **投稿の既定**（設定 → 投稿。**公開範囲**・**センシティブにする**・**CW に入れておく文言**・**画像を自動で軽くする**（上げる前に長辺 2048px の WebP）・**よく使うリアクション**・**キーボードショートカット**）
- **見え方の設定**（設定 → 表示。**時刻の書式**（日時 / 〜前）・**カスタム絵文字を画像で出す**・**センシティブな添付はいつも隠す**・**動画の自動再生**・**動画はミュートで始める**）
- **キーボードショートカット**（設定 → 投稿 で入にすると効く。n 投稿 / / 検索 / ? 一覧 / g h・g l・g f タブ切替 / j k ノート移動）
- **自分の活動**（設定 → データに**リアクションの履歴**、自分のプロフィールに**投稿カレンダー**（月ごとの件数。前月/次月に移動できる））
- **ホーム画面に追加（PWA）**（`manifest.json` と 192/512 のアイコン。ショートカット「新規投稿」「検索」、共有シートから本文を受け取る。
  設定 → 表示 に「ホーム画面に追加」の導線。アイコンのバッジに未読数を出します（対応端末だけ））
- **レスポンシブ**（900px 以下で左上アバター → ドロワー、下部バー、投稿ボタン）
  - タブは語の途中で折り返さない（入りきらないときは横に流す。設定の節は 2 行に折り返す）
  - ドライブは 2 列・正方形のサムネ・指で押せる削除ボタン
  - メッセージは開いた時点で最新（書き込み欄）まで送る

**足すときの決めごと**

- `App.tsx` に機能を足さない（画面は `views/`、部品は `components/`、ロジックは `lib/` へ）
- 見た目の値は `styles/` にだけ書く（コンポーネントに色や px を書かない）
- 投稿カードを 2 つ作らない（通知も検索も同じ `PostCard` を使う）

## 開発サーバーの転送（まめ知識）

`vite.config.ts` の `proxyPaths` には**サーバーにしか無いものだけ**を入れています（`/api`・`/uploads`・`/proxy`・`/.well-known` など）。
`/users/…` や `/tags/…` のような**画面のパスは入れない**でください。入れると開発サーバーがサーバーの `index.html` を返してしまい、
画面が空になります（実際に一度これを踏みました）。

## 既存クライアントとの関係

- トークンの保存先は同じ `localStorage` キー（`spica_token`）を使う。**同じオリジンで配信するようになれば、ログイン状態はそのまま引き継がれる**
- サーバーの API は変えていない（`server/` には触っていない）
- いまは別ポート（5174）で動くので、`3210` のアプリと見比べられる
