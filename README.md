## 🌟 Spica とは？

Spica は、W3C 標準規格 **ActivityPub** に完全準拠した自律分散型SNS（Fediverse）サーバーソフトウェアです。  
世界中の Misskey、Mastodon、Firefish 等のサーバーと自由にフォロー・ノート送受信・リアクションの交換ができます。

重厚なミドルウェア（PostgreSQL や Redis など）を必要とせず、**Node.js と SQLite (FTS5)** だけで驚くほど軽量かつ高速に動作します。自宅サーバー、VPS、Raspberry Pi でも数分で自分専用の独立した主権型SNSノードを立ち上げることが可能です。

## ✨ 主な特徴

- 🌐 **ActivityPub / Fediverse 完全相互運用**
  - ノート作成、返信、リノート、引用、メンション、ハッシュタグ、CW（閲覧注意）、アンケート投票
  - リモートフォロー、フォロワー管理、WebFinger、NodeInfo 2.1、公開鍵署名（HTTP Signatures）
  - 連合リレー（YUKARI、Akkoma等）への接続と送受信に対応
- 🔑 **データ主権 ＆ パスワードレス認証（マスターキー）**
  - 個人情報（メールアドレス・電話番号など）を一切収集しません。
  - アカウント登録時に暗号学的に安全な **マスターキー** が発行され、ユーザー自身がアカウントの完全な所有権を持ちます。
- 📦 **ワンクリック データエクスポート**
  - 「自分のデータは自分のもの」。過去の全投稿、フォロー・フォロワー一覧、ブックマーク、リアクション履歴をいつでも **JSON または ZIP アーカイブ** 形式で一括ダウンロードできます。
- 🔍 **SQLite FTS5 高速日本語全文検索**
  - ハッシュタグだけでなく、過去の膨大な投稿本文から目的のキーワードを瞬時に全文検索できます。
- 🔔 **PWA ＆ Web Push 通知**
  - ホーム画面に追加してネイティブアプリのように利用可能。
  - ブラウザやアプリを閉じていても、自分宛ての返信やリアクションを端末の通知欄へリアルタイムにお届けします。
- ☁️ **S3 / Cloudflare R2 互換オブジェクトストレージ連携**
  - 画像などのメディアは、Cloudflare R2 や Amazon S3 などの外部ストレージへ直接保存・配信可能。ローカル保存へのフォールバックも完備。
  - アップロード時に**サーバー側でメタデータ（位置情報など）を除去し WebP へ変換**するため、プライバシーを保護しつつ容量を節約できます。
- 🔒 **3段階の公開範囲**
  - 公開（連合配信）／ローカル限定／**フォロワー限定**を投稿ごとに選択できます。フォロワー限定の投稿は承認済みフォロワーのみが閲覧でき、連合先へはフォロワーの Inbox にだけ届きます（リレーには配信されません）。※ダイレクトメッセージ（DM）は未対応です。
- 🚩 **通報とモデレーション**
  - 投稿・ユーザーを通報でき、管理画面の「通報」タブに未対応件数つきで集約されます。対応済み／却下／再オープンの管理が可能です。
  - 他サーバーのユーザーを通報すると、相手サーバーへ ActivityPub の **Flag** として転送されます。他サーバーから届いた通報も同じキューに取り込みます。
- 🚦 **レート制限**
  - 認証・API・Inbox ごとに IP 単位のレート制限を備え、総当たりやスパム投稿、flooding を抑止します（`RATE_LIMIT_DISABLED=true` で無効化可能）。
- 🔇 **ワードフィルター（ミュートワード）**
  - 除外したいキーワードを登録すると、本文・CW が一致する投稿をタイムラインやアンテナから自動的に除外します（大文字小文字の区別／単語単位の指定に対応）。
- 🔒 **鍵アカウント（フォロー承認制）**
  - オンにすると新しいフォローは承認制になり、設定画面から承認・拒否できます。承認した相手だけがフォロワーになり、フォロワー限定の投稿が届きます（連合先へは `manuallyApprovesFollowers` として伝わります）。
- 📢 **お知らせ（運営からの一斉告知）**
  - 管理画面の「お知らせ」タブから告知を投稿できます。公開中のお知らせは全ユーザーのタイムライン上部にバナー表示され、不要なものはユーザー側で閉じられます。
- 🔗 **リンクプレビューカード（OGP）**
  - 投稿本文に URL を書くと、OGP（タイトル・説明・画像・サイト名）を自動取得してカード表示します。取得結果はキャッシュされ、SSRF 対策・サイズ/時間制限つきで安全に動作します。
- 🔔 **メンション通知**
  - 本文中の `@user` で相手にメンション通知を届きます。自分自身・存在しない相手・他ドメイン宛は通知せず、返信相手への重複通知も避けます。
- 📥 **アカウント移行インポート**
  - Mastodon の `outbox.json` / Misskey の `notes.json` を取り込み、過去の投稿（本文・CW・公開範囲・**元の投稿日時**）を復元します。同じファイルを再取り込みしても重複しません。
  - エクスポートと合わせて「データ主権」の往復が成立します。※メディアとフォロー/ブックマークの取り込みは今後の対応です。
- 📋 **リスト（専用タイムライン）**
  - ユーザーを束ねたリストを作成し、メンバーの投稿だけを時系列で表示できます（公開範囲とミュートワードを尊重）。サイドバーの「リスト」から管理・閲覧できます。
- 🎬 **動画・音声の添付**
  - 画像に加えて、動画（MP4/WebM/MOV）と音声（MP3/OGG/WAV/M4A）を添付できます。動画・音声は1投稿につき1件・最大50MB（`MEDIA_MAX_BYTES` で変更可）、画像は従来どおり最大15MBです。
  - 添付は ActivityPub でも `Document` として連合先へ届きます（サーバー側で再エンコードは行いません）。
- 🔎 **検索演算子**
  - 検索欄で `from:user` / `before:2026-09-01` / `after:2026-01-01` / `has:media` / `-除外語` が使えます（併用可・演算子のみの検索も可）。全文検索（FTS5）と部分一致の両方に適用されます。
- 📡 **RSS / OGP / oEmbed（発見性）**
  - `GET /feed.xml`（ローカル公開タイムライン）と `GET /users/<id>/feed.xml`（ユーザー別）で RSS 2.0 を配信します。公開投稿のみが対象です。
  - 投稿URL（`/?post=<id>`）とプロフィール（`/users/<id>`）のHTMLに **OGP / Twitter Card を動的注入**するため、他SNSでシェアしたときにカードが表示されます。
  - `GET /api/oembed?url=<投稿URL>` で他サイトへ埋め込めます。
- 📜 **サーバールール設定 ＆ 新規登録同意フロー**
  - Misskey スタイルのサーバールール、利用規約、プライバシーポリシーを管理画面から自由に設定可能。
  - 新規登録時に丁寧な同意モーダルを表示し、健全なコミュニティ運営をサポート。
- 🔄 **カーソル方式ページネーション**
  - タイムライン・プロフィール・ブックマーク・通知・チャンネル・アンテナを、過去へ遡って読み込めます。
  - サーバーは `X-Next-Cursor` ヘッダで続きのカーソルを返し、ActivityPub の outbox も `first` → `next` で全ノートを辿れる形式で配信します。

## 🚀 クイックスタート (ローカル起動)

### 前提条件
- **Node.js**: v20.0.0 以上 (v22 / v24 推奨)
- **npm**: v9.0.0 以上

### 1. リポジトリのクローン
```bash
git clone https://github.com/Keychrom/Spica.git
cd Spica
```

### 2. 依存パッケージのインストール
```bash
npm install
```

### 3. 設定ファイルの準備
```bash
cp .env.example .env
```
※ローカル開発の場合は、デフォルト設定のまま利用可能です。

### 4. 開発サーバーの起動
```bash
npm run dev
```
起動後、ブラウザで [http://localhost:5173](http://localhost:5173) にアクセスしてください。

## 🛡️ セキュリティとプライバシー

- **HTTP Signature 検証の強制**: 受信した Activity は、署名鍵の持ち主と `actor` の一致・ボディの Digest 一致・署名の鮮度をすべて検証し、失敗したものは **401 で拒否**します（`INBOX_SIGNATURE_MODE=strict`、既定）。なりすまし投稿や改ざん・リプレイを防ぎます。署名鍵の取得先は SSRF 対策としてプライベートアドレス・内部ホスト名を拒否します。
- **パスワードレス**: パスワードの平文やハッシュの漏洩リスクがありません。
- **データ主権**: ユーザーが希望すればいつでも自身のアカウントと過去投稿を連合先（Fediverse）を含めて完全削除可能。
- **機密情報の保護**: 本番環境の `.env` や SQLite データベースファイルは Git 追跡から厳重に除外されています。
