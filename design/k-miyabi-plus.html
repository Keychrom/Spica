03システム（エレガンスの規則）

上質さは、規則の少なさと規律の高さから出します。ここも画面と同じトークンで描いています。

字面と余白の規則

この案の上質さは装飾ではなく、次の 3 つから出ています — 書体の使い分け、数字の等幅、行長と余白の制限。すべて検査できます。

色（案B / 案I から）

--bg#F4F5FA地
--paper#FFFFFF面（カード・シート・ドロワー）
--surface#FAFBFF淡い塗り（アバター・選択）
--line#E8EAF3罫
--text#191C26字
--text-sub#5D6474副字
--accent#6D5AE6操作（サイドバーの作成ボタン）
--accent-soft#EFECFD選択面・新着・リアクション
--pearlgradientロゴだけ

書体は 1 系統だけ（2026-10-09 変更）

sans 700題字・画面名（太さで階層を作る）
sans本文と UI（読む部分はゴシック）
mono時刻・件数・票数の数字だけ

段は 5 つ

--t-title画面名 22
--t-name名前 15
--t-body本文 15 / 行間 1.9
--t-sub副 12.5
--t-labelラベル 11（字間を開ける）

形は 2 つ + 影は 2 つ

--r-card10px（面・入力・画像）
--r-pill999px（ボタン・タグ・リアクション）
--shadow-1浮かない面（カード）
--shadow-2浮く面（モーダル・引き出し）だけ

部品（すべてトークンで描く）

ノート フォロー キャンセル あとで 検索 ★4✦2＋

構造

App ├─ Nav … 常設（画面で消えない） └─ Screen ├─ ScreenHead … 画面名（タブに追従）+ 件数 ├─ HeadRow … セグメント + 新着ピル + リロード（案B の部品・寸法は案H） ├─ Divider ├─ Feed │ └─ Post × n │ ├─ Avatar（円・静かな輪） │ ├─ Meta（名前 / ハンドル / 時刻 等幅 / 公開範囲） │ ├─ Body（行長 62 字まで） │ ├─ CW / Media / Quote / Poll │ ├─ Reactions … 細い縁のピル │ └─ Actions └─ Aside … 静かなカード

検査できる規則

  • 本文の行長は 62 字以内（max-width: 62ch）grep
  • 数字（時刻・件数）は tabular-nums を必ず付けるgrep
  • 書体は 1 系統だけ（追加の書体を読み込まない）レビュー
  • 彩度の高い色を増やさない（アクセント 1 色 + 金 1 色まで）レビュー
  • 影は --shadow-1/-2 以外を使わないgrep
  • ボタンは丸（pill）。角のある塗りボタンを作らないレビュー
  • 上部の操作（タブ・新着・リロード）はサイドバーと同じ言語（角丸 10・淡い塗り・影なし）で描くレビュー
  • ソリッドなアクセント塗りは「ノートを作成 / 投稿」だけ（それ以外は淡い面）grep
